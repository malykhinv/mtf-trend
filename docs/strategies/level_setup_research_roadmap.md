# Роадмап исследования уровневых лонг-сетапов (до OOS включительно)

Строгий научный план. Пред-регистрируется ДО просмотра исходов широкой популяции.
Все фазы 0–6 — **только IS** (до `DEV_END_MS = 2026-01-01`). OOS вскрывается один
раз в фазе 7.

## Сквозные инварианты (нарушение = стоп)
- **IS-only до фазы 7.** OOS не трогаем ничем.
- **Заморозка до исходов.** Определения, признаки, входы/выходы, метрика, сетки
  свипов регистрируются ДО того, как считаются исходы широкой популяции.
- **Контроли всегда.** Любое утверждение об эдже = против blind base-rate И
  shuffled, на weekly-walk-forward-внутри-IS.
- **Дедуп.** Один памп-ивент на символе = одна сделка; перекрывающиеся не
  независимы.
- **По-семейно.** breakout / cap / structure_break — раздельно, свои признаки.
- **Frozen core.** Входы/выходы/трейл — конфиги через `simulate_long_path`, без
  новых симлупов.
- **Многокритериальность.** сделки/день × винрейт × реализованный R ×
  позитивность дней × **независимость от топов** (убрать top-k → всё ещё плюс).
- **Ручные метки = discovery + якорь, не тест-выборка.**

---

## Фаза 0 — Регистрация (заморозка до исходов)
Из ручной выборки (discovery) фиксируем и записываем в конфиг:
- **Определения сетапов** по семействам (breakout=уровень 3+ касаний; cap=то же +
  хай пампа сверху; structure_break=главный хай→нисходящие свинги→пробой
  последнего свинг-хая) + параметры детектора; **сетку ширины свингов** — a priori.
- **Список признаков-кандидатов** по участкам (+ ожидаемые знаки).
- **Режимы входа** (close/break/anticipation) и **политики выхода** (трейл по
  свинг-лоям + эксперименты: импульс, N·R, круглое, частичное) + сетки.
- **Метрику исхода** (frozen-core net_r, MFE/MAE-в-R) и **целевую функцию**.
- **Правило дедупа**.
→ Артефакт: зарегистрированный конфиг (аналог `pump_long/spec.py`).
**Гейт:** пока не заморожено — исходы широкой популяции не смотрим.

## Фаза 1 — Широкая непредвзятая IS-популяция
- Механический детектор по правилам фазы 0 → прогон по ВСЕМ символам IS.
- Каждый детект (пробои И заглохи) → каузальные признаки на баре-решения +
  frozen-core форвардный исход (окно цензурируется на `DEV_END_MS`).
- Дедуп. QA: размер по семействам, покрытие; визуальная сверка сэмпла с ручными
  метками (детектор ловит то, что человек назвал бы сетапом?).
**Гейт:** детектор согласуется с экспертным якорем на разумной доле.

## Фаза 2 — Blind base-rate + shuffled (нуль-модель)
- Blind: взять ВСЕ детекты (по семейству/входу/выходу) → базовый эдж (или его
  отсутствие) в R и по целевой функции.
- Shuffled: перестановка меток/признаков → должно схлопнуться.
**Гейт / kill-criterion:** если у определения нет даже намёка на blind-эдж и
признаки его не поднимают (фаза 3) — стоп, сетап не рабочий. Пред-коммит на смерть.

## Фаза 3 — Проверка признаков-гипотез на широкой популяции
- Замороженные признаки (вертикальность, простор до хая, здоровье отката,
  **объём на подходе — теперь честно: пробои vs заглохи**) против исхода:
  weekly-GroupKFold-внутри-IS AUC vs blind + shuffled; SHAP; сверка знаков с
  зарегистрированными ожиданиями.
- Здесь же честный тест упреждающего входа (нужны заглохи — они тут есть).
**Гейт:** какие признаки реально разделяют (переживают shuffled).

## Фаза 4 — CatBoost-ранкер (по-семейно): база + доводка
- База: CatBoost на широкой популяции (форвардный таргет) с параноидальной
  валидацией (GroupKFold-по-неделям, blind, shuffled, пофолдовый AUC).
- Доводка: якорь человеческими good/ok (init_model / веса); проверка, что
  ранжирование модели согласуется с якорем.
**Гейт:** OOF-внутри-IS AUC бьёт blind И shuffled коллапсирует — иначе модель
выкидываем, работаем на голом определении.

## Фаза 5 — Оптимизация входа/выхода (через frozen core)
- На отобранных моделью сетапах: свип зарегистрированных входов × выходов ×
  ширины свингов — через `simulate_long_path`.
- Оценка по многокритериальной функции; выбор по **устойчивости**, не по пику;
  weekly-walk-forward-внутри-IS.
**Гейт:** конфиг устойчив (не держится на нескольких топах/неделях).

## Фаза 6 — Портфель и деньги (всё ещё IS)
- Конкуренция позиций + дедуп на портфельном уровне; свип риска 2–5%,
  просадка/риск разорения по всему диапазону; перевод R-эджа в эквити.
**Гейт:** эквити-результат устойчив (независимость от топов на кривой).

## Фаза 7 — Заморозка → OOS (один выстрел)
- Фиксируем ФИНАЛЬНУЮ конфигурацию (детектор, признаки, веса модели, вход/выход,
  сайзинг) из IS.
- Один прогон на OOS (после `DEV_END_MS`). Без подстройки, без итераций.
- Отчёт против пред-зарегистрированного IS-ожидания. Держится → реально;
  не держится → честный минус.

---

## Роль компонентов
- **Механические правила** — детектор сетапа (фаза 1). Определяет популяцию.
- **CatBoost** — по-семейный ранкер отбора качества (фаза 4). Работает, только
  если бьёт blind+shuffled; иначе не используется.
- **Frozen core (`simulate_long_path`)** — исполнение/выход (фазы 1,5). Косты
  внутри. Никаких новых симлупов.
- **Ручные метки** — источник определения + признаков (фаза 0) и экспертный якорь
  (фазы 1,4). Не тест-выборка.
