# Кандидаты На Успех

Здесь лежат не просто красивые результаты, а понятные кандидаты на рабочий edge по гипотезе `XX:00` в азиатскую сессию.

Что считаем кандидатом:
- есть честный full-year результат;
- правила единые для всех `XX:00`, без hour-specific развилок;
- есть понятное объяснение, почему сетап вообще должен работать;
- известны слабые места и ограничения.

Статусы:
- `Ядро` — чистый и устойчивый слой, который можно держать как базу.
- `Рост` — кандидат на усиление доходности, если не ломается устойчивость.
- `Агрессивный` — умеет зарабатывать сильно больше, но уже с заметной хрупкостью.
