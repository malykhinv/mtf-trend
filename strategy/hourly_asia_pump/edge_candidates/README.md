# Edge Candidates

This folder keeps the best-known edge notes for the anomaly-pump research.

What qualifies as a candidate:
- the rule logic is coherent and reproducible
- the entry, stop, and exit are explicit
- the result is honest enough to discuss in production terms
- known limits and failure modes are written down

Status labels:
- `Core` means the best-known base layer for the current research direction
- `Growth` means a return-focused extension that may still be less stable
- `Aggressive` means higher upside with more fragility
- `Exploratory` means promising, but not ready to be treated as a stable edge
- `Red flag` means the cleaner validation pass did not confirm a deployable edge
