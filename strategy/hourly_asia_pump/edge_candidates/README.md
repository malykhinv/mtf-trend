# Кандидаты на успех

Здесь лежат не просто красивые цифры, а рабочие кандидаты на edge по гипотезе аномальных пампов и их продолжения или выдоха.

Что считаем кандидатом:
- правила едины внутри своей идеи и не опираются на разные сценарии для разных часов;
- есть честный full-year результат;
- понятна логика входа, стопа и выхода;
- известны слабые места и ограничения.

Статусы:
- `Ядро` — чистый и устойчивый слой, который можно держать как базу.
- `Рост` — кандидат на усиление доходности без сильного развала по месяцам.
- `Агрессивный` — вариант с более высокой доходностью, но уже с большей хрупкостью.
- `Разведка` — интересный след, который пока не дотягивает до финальной стратегии.
