# C01 - Confirmed Core TP5

Статус: `Ядро`

Идея:
- аномальная `5m` свеча ровно в `XX:00`;
- следующая `5m` свеча подтверждает продолжение;
- вход только после этого подтверждения;
- выход фиксированным `TP 5%`, стоп под аномалию.

Правила:
- `sig_70`
- `confirm_50g`
- `tp5_full`
- `trigger >= 7.0%`
- `range_atr >= 8.5`
- `volume_mult >= 12`
- `close_to_high <= 0.14`
- `next bar pullback <= 50%`
- `next bar low >= 25% диапазона аномалии`
- `stop = trigger_low`

Почему это кандидат:
- очень высокий `WR`;
- мало зависимости от топ-символов;
- очень понятная логика руками;
- почти нет сложного сопровождения.

Метрики:
- `24.9` сделок/год
- `mean trade = +3.21%`
- `WR = 85.2%`
- `annualized unit pnl = +80.1%`
- `max DD = 12.0%`
- `10` плюсовых месяцев
- `7` устойчивых плюсовых месяцев

Капитал:
- при `3%` риска: `+15.5%` годовых, `DD 3.62%`
- при `4%` риска: `+21.1%` годовых, `DD 4.82%`
- при `5%` риска: `+26.9%` годовых, `DD 6.00%`

Слабое место:
- слишком широкий стоп под аномалию;
- слишком мало сделок;
- для сильного CAGR этого недостаточно.
